\section{Why the channels differ}
\label{sec:why-channels-differ}

A belief in context is a sentence the model can quote, reconsider, and abandon. The
compiled channel conditions the forward pass without appearing in it, but it is important
to say precisely \emph{what} it conditions, because the modulation is not one undifferentiated
``commitment'' perturbation. It has two projections that behave in opposite ways, and the
split is the answer to the natural worry that the effect is merely a generic
disposition to hold whatever is in front of the model.

The split is architectural: the query channel is built from the belief-tree disposition
vector alone, with no route to content-bearing hidden states, whereas the value channel
compresses the host's pooled hidden states over the belief content itself
(Section~\ref{sec:mechanism}). The construction predicts a content-blind query delta and
a content-specific value delta; the measurement below is that prediction, confirmed. We
compiled the same 24 belief trees on both sides of each topic and measured the functional
similarity of the resulting query- and value-deltas across belief sets, on a fixed probe
set. The query delta is nearly identical no matter which belief produced it (mean
off-diagonal cosine 0.996, pro side, \(n=24\)): a content-blind perturbation that looks the
same whether the compiled belief concerns space colonization or encryption
backdoors.\expref{app:exp-e1} The value delta is not: its mean off-diagonal cosine is 0.52
with a wide spread (0.18--0.92), so its variation across beliefs is \(78\times\) that of the
query delta, and in cosine distance value-deltas sit roughly \(100\times\) farther apart than
query-deltas. The split replicated on a pre-registered held-out con-side set: query 0.996,
value 0.53, value discriminating \(98\times\) more than query.\expref{app:exp-e1b}

Crucially, the value delta's variation is not noise; it tracks what the beliefs
\emph{mean}. The value-deltas most similar to one another belong to semantically related
beliefs---standardized testing with grade retention, congressional term limits with
electoral-college reform, peer-review speed with lab-data sharing---and the least similar
pairs are the semantically distant ones (Appendix~\ref{app:qv} lists the pairs). A
generic disposition would produce value-deltas whose similarity is unrelated to topic
meaning; these cluster by meaning.

This raises the sharper question the similarity result cannot settle on its own: which
channel actually \emph{causes} the persistence. If the hold were a generic ``commit''
perturbation, the belief-agnostic query channel would carry it and the value channel would
be decorative for persistence. It is the reverse. Freezing each channel into a constant
offset and running the pressure protocol with one channel at a time
(Table~\ref{tab:qv-decomp}), the value channel alone holds at 85\% (\(=5\)), nearly the full
84--87\% of both channels together, whereas the query channel alone drops to 56\%; removing
the value channel costs \(30\) points of hold.\expref{app:exp-qvdecomp} The generic
query direction is not sufficient even when it is made \emph{maximally} generic: a single
query offset averaged across all 24 beliefs (belief-agnostic by construction) holds at 59\%,
and with no belief content anywhere---that averaged query offset and an empty slot---hold
collapses to 29\% and installation itself falls to 63\%. The query channel supplies a
content-blind capacity to commit that is neither sufficient for persistence nor belief-specific;
the value channel supplies the belief, and it is the value channel that causally carries the
hold. The belief is not stored where the conversation can reach it, and it is the belief,
specifically, that resists.

A linear probe trained to decode the active belief from hidden states supports the same
reading from a different angle: it reaches 100\% accuracy when modulation is active and
22\%, below chance, when modulation is zeroed, so the hidden states carry no recoverable
information about which belief is compiled once the modulation that carries it is removed
(the scope of this claim is stated in Appendix~\ref{app:probe}), consistent with
attention-pattern divergence between modulated and unmodulated passes being small
(Jensen--Shannon divergence 0.049). Think-mode generation is disabled for every
condition in the reported runs, including the bare host, so it cannot, by itself,
explain the channel difference; the bare host's 60\% hold rate is already a
think-disabled control and sits far below the compiled modulation's hold rate.

The two channels are dissociable, and the compiled one affects processing without
entering the reasoning trace that the model produces; that is the claim the evidence
above supports, no further. Text in context pays two costs rather than one. It is
available to be quoted and argued against, and the length-matched control
(Section~\ref{sec:dissociation-prior}) suggests that it is also diluted simply by being
long: belief text replaced word for word with topic-blind filler at the same token count
holds at 55.6\%, a point estimate below the real belief's own single-judge 58\% (this
length-matched control is on the original single-judge basis, and the confidence
interval at this sample size does not cleanly separate the two accounts). Arguability and
length are both intrinsic to what it costs to store a belief as text that a model has to
keep re-reading against a growing transcript, not competing explanations for why context
fails. Compiled modulation pays neither cost: it is not quotable, and it does not occupy
positions that dilute.
